# Stage 1 approved assets

This pack contains the reviewed Stage 1 assets for the top-down 2D Granfloris-inspired forest.

- `stage1_background/forest_floor_room.png`: use once per room as the fixed floor backdrop; do not repeat as a 32×32 tile.
- `stage1_forest_foreground/`: trees, bushes, guardian stones, and root-vine edges. Draw these above the floor and use their alpha channel.
- `stage1_interactive_objects/`: chest, portal, fountain, crate, flowers, and campfire.
- `stage1_goblins/`: 48×48 horizontal sprite strips. File suffixes document the frame count.
- `stage1_tau/`: 64×64 tau warrior and 96×96 tau chief horizontal sprite strips.
- `stage1_combat_effects/`: horizontal sprite strips. File suffixes document the frame count.

All PNGs use RGBA, have verified dimensions, and preserve transparent backgrounds. The fixed room floor is a large backdrop, not a seamless terrain tile.
