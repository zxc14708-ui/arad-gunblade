# Elden Garden × Gran Flores Pixel Asset Set

Original 16-bit pixel assets for ARAD: Gunblade.

- Tiles: 32×32 seamless candidates
- Props: native dimensions requested
- Monster animation sheets: horizontal frames at the requested cell size
- Art direction: mossy forest ruins, bright sanctuary stone, teal life magic and restrained crimson corruption

All files are original work; do not represent official Dungeon & Fighter artwork.
