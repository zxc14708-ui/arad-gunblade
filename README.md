# ARAD: Gunblade — 던전앤파이터 팬 게임

> 화면·스프라이트 제작 기준은 [`ART_GUIDE.md`](ART_GUIDE.md)를 따른다.
> 게임 내부 기준 해상도는 1920×1080(16:9)이며, 브라우저 크기에 맞춰
> 전체 화면을 같은 비율로 확대·축소한다.

던전앤파이터의 **총검사(Gunblade)**를 주인공으로 한 2.5D 픽셀아트 로그라이크 핵앤슬래시 팬 게임입니다.
Three.js로 제작되었으며, 브라우저에서 바로 플레이할 수 있습니다.

> ⚠️ 본 프로젝트는 비영리 **팬 게임**입니다. Dungeon &amp; Fighter는 NEOPLE/NEXON의 지적 재산입니다.

## 🎮 게임 소개

리볼버와 카타나를 함께 다루는 총검사가 되어, 마을에서 장비와 특성을 갖추고
무작위로 생성되는 던전을 돌파합니다. 방을 클리어할 때마다 특성을 획득해
점점 더 강력한 빌드로 보스에게 도전하세요.

- **마을 ↔ 던전** — 마을에서 무기 해금·영구 강화·시작 특성 선택 후 포탈로 던전에 입장
- **총검 이중 무기** — 좌클릭 리볼버 연사(탄창제 + 재장전) + 우클릭/Space 카타나 광역 베기
- **선형 분기 던전** — 깊이 1~9의 단방향 분기 구조(되돌아가기 불가능). 4층은
  상점, 8층은 보스 준비 장소, 9층은 보스로 고정, 나머지 깊이에서 방 종류를
  선택
- **방 종류** — 전투 / 상위 전투 / 각인 / 엘리트 / 회복 / 상점 / 보스 준비
  장소 / 보스
- **각인 성장** — 슬롯 3축(총/검/캐릭터), 핵심 슬롯 특성(축당 1개) + 각인
  26종(5등급: 노멀→레어→유니크→레전더리→에픽, 재획득 시 승급)
- **영구 성장** — 브라우저에 저장되는 힘의 결정·제단 강화·무기 설계도 해금
- **엘리트 접두사** — 재생·신속·가시·분열·폭발·보호막으로 방마다 다른 전투 규칙 제공
- **보스 패턴** — 돌진·슬램·사격, 체력 75%/25% 브레이크(기절), 50% 2페이즈 전환
- **다양한 적** — 임프(근접 고블린) · 슈터(화염 고블린, 원거리) · 브루트(타우 전사) · 보스(타우 족장)

현재 구현 범위와 다음 작업은 [`PROJECT_STATUS.md`](PROJECT_STATUS.md), 설계 판단과
변경 이력은 [`DESIGN_LOG.md`](DESIGN_LOG.md)에서 관리합니다.

## ⌨️ 조작법

| 키 | 동작 |
| --- | --- |
| `W` `A` `S` `D` | 이동 |
| `마우스` | 조준 |
| `좌클릭` (홀드) | 리볼버 연사 |
| `우클릭` / `Space` | 카타나 베기 (광역 + 넉백) |
| `R` | 재장전 (수동, 탄창 소진 시 자동) |
| `E` | 상호작용 |
| `Shift` | 대시 회피 (짧은 무적) |
| `Tab` | 설정창 / 조작 키 변경 |

## 🕹️ 실행 방법

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
```

프로덕션 빌드:

```bash
npm run build    # tsc 타입 체크 + dist/ 생성
npm run preview  # 빌드 결과 미리보기
```

시각적 회귀 검증(빌드 → 헤드리스 플레이 → 스크린샷):

```bash
npm run qc       # qc-out/ 에 contact.png, 단계별 스크린샷, report.txt 생성
```

`npm run build`는 타입만 검사하므로 스프라이트 크기/앵커/이펙트 배치 같은
시각적 버그는 잡지 못합니다. 변경 후에는 항상 `npm run qc`로 `qc-out/contact.png`를
직접 확인합니다.

## 🏘️ 마을 / 던전 시설

마을 입장 시 이미 완전 회복되므로 마을에는 회복 시설이 없다(중복이라 P7에서
제거). 특성 제련소도 마을이 아니라 던전 내 유료 시설(던전 제련소)로 옮겨졌다.

| 시설 | 위치 | 기능 |
| --- | --- | --- |
| 던전 포탈 | 마을 | 현재 스테이지 던전 입장 |
| 상인 | 마을 | 무기 설계도 해금(영구 재화) |
| 시작 특성 제단 | 마을 | 런 시작 시 첫 특성 선택 (런당 1회) |
| 힘의 제단 | 마을 | 힘의 결정으로 영구 능력 강화 |
| 회복 우물 | 던전(`recover` 노드) | 체력 회복(유료, 던전 첫 사용 무료) |
| 던전 상점 | 던전(`shop` 노드) | 런 골드로 아이템 구매·판매·리롤 |
| 던전 제련소 | 던전 | 보유 각인 중 하나를 유료로 교체 |
| 보스 준비 장소 | 던전(깊이 8, 고정) | 상점·회복 우물 이용 |

```
src/
├── main.ts                  # 진입점, window.__game QC 훅

├── systems/
│   ├── RunState.ts             # 선형 분기 던전 맵 생성(깊이 1-9) · 진행 상태
│   ├── Room.ts                 # 방 경계 · 출입구 좌표
│   ├── Shop.ts                 # 골드 상점
│   ├── Upgrades.ts             # 특성/각인 풀 (슬롯 3축, 각인 5등급)
│   ├── Pickups.ts              # 골드 오브 획득
│   ├── Projectiles.ts          # 총알 / 적 투사체
│   ├── Effects.ts               # 파티클·베기 궤적·사망 연출
│   └── Audio.ts
├── rendering/
│   ├── assets.ts                # 픽셀 애셋 경로/로더
│   ├── tiles.ts                 # 바닥/벽 타일링
│   ├── toon.ts                  # 셀 셰이딩 아웃라인
│   └── pixelfx.ts
└── ui/
    └── HUD.ts                    # HP·골드·미니맵·상호작용 프롬프트·특성 선택·상점 UI
```

## 🎨 아트 & 기술 스택

- 픽셀아트 스프라이트 시트 기반 2.5D 빌보드 렌더링 (Three.js 직교 카메라)
- 플레이어/적 스프라이트는 상태별(대기·이동·공격) 가로 스트립 시트, 발이 셀 하단에 정렬
- [Three.js](https://threejs.org/) — 렌더링
- TypeScript + Vite
- Playwright 기반 헤드리스 시각 회귀 검증 (`tools/qc.mjs`)
