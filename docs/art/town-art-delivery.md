공통 높이 약52아트픽셀, 4fps 대기 루프. 호흡·눈깜박임 중심이다.
생성 원화는 `source/`, 최종 픽셀 격자 및 색 제한은 `pack.mjs`에서 확정한다.
원화 생성 자체의 출력 크기가960×540이었다고 주장하지 않는다.

## 비율·배치와 적용 경계

- 배경과 캐릭터를 모두 1아트픽셀=화면2px로 표시한다.
- v3는 대장간·선술집·노점·아치와 부속 소품의 체감 축척을 v2 대비 약78%로 줄였다.
- NPC 높이52아트픽셀을 유지하고 문 개구부를 캐릭터보다 조금 큰 수준으로 맞췄다.
- 기존 시설좌표 대장간(0.18,0.66), 선술집(0.58,0.66), 노점(0.73,0.66)을 유지했다.
- 보행띠 y64~92%에 서 있는 소품이 없도록 전경 식물을 하단으로 내렸다.
- `index.html`은 현재 플레이어/SD후보를 전환하며 NPC3명의 대기 모션과 동선을 비교한다.
- `town-preview.png`와 `town-sd-preview.png`는 독립 아트 합성 캡처이며 실제 게임 캡처가 아니다.
- `src/rendering/assets.ts`의 `PICTURE_TOWN_ART`에 경로/프레임을 등록했다.
- 실제 그림 마을 구현에 배경을 연결하고 기존 시설 대체 그림을 애니메이션 NPC로 교체하는 것은 남아 있다.
- 마을 카메라 확대나 던전④ 카메라/지형 수치는 변경하지 않았다. 먼저 요청된 픽셀밀도와 문:NPC 비율을 적용한 시안이다.

## 재현·검증

1. `node docs/art/town-npcs/pack.mjs`
2. `node docs/art/town-npcs/verify.mjs`
3. `npm run qc` 및 `qc-out/contact.png` 검토

전용검사는 크기·각 프레임 존재/고유성·발기준·모서리·이진알파·64색 제한·
배경 전체 픽셀의 정확한2배 복제와 미리보기 조작/오류를 확인한다.
게임 QC는 현재 checkout의 기존 동작 회귀검사다. 신규 NPC의 실제 상호작용을 검증한 것이 아니다.

남은 검토: 실제 마을 병합 후 NPC 이름표/HUD 대비·상호작용 범위·표시배율 확인.

## v3 축척 수정

사용자 피드백에 따라 캐릭터와 NPC 크기는 그대로 두고 배경 쪽 건물·문·간판·
노점·아치·나무와 부속 소품만 약22% 작아 보이도록 다시 구성했다. 시설 순서와
대략적인 화면 좌표, y64~92% 보행띠, 하단4% 전경 식물 규칙은 유지했다.
기존 v2는 비교·복구용으로 보존하고 PICTURE_TOWN_ART와 미리보기는 v3를 사용한다.

v3 전용 검사와 전체 프로젝트 QC 42/42를 통과했고 콘솔·네트워크 오류는 0건이다.
`qc-out/contact.png`, `town-preview.png`, `town-sd-preview.png`, `town-guides.png`를
육안 확인했으며 `git diff --check`도 통과했다. 생성·편집에는 built-in imagegen을 사용했다.

## 프로젝트 검사 보완

`tools/measure_sprites.py`는 새 배경 두 경로만 불투명 그림 맵으로 분류하고
각각의 크기·전체 불투명·64색 제한을 검사한다. NPC를 포함한 다른 파일은
기존 투명 모서리 검사를 그대로 받는다. 최초 QC의 배경 모서리 오류를 수정했다.
