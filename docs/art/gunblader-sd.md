# SD 총검사 모션 시트

사용자 첨부 총검사 일러스트의 은발·안경·흰 코트·올리브색 상의·총과 장검을
현재 게임의 SD 캐릭터 규격에 맞춘 후보 시트. 이미지 생성은 built-in image_gen 사용.
완성 PNG는 `public/assets/characters/gunblader-sd/`, 등록은 `src/rendering/assets.ts`의
`GUNBLADER_SD`. 기본 `public/gunblader.png`와 기존 게임 동작은 교체하지 않았다.

## 납품 목록

### X자 2연속 베기 수정본

- `attackX.png`: 12프레임, 1344×64. 내려 베기 → 자세 전환 → 올려 베기로 X 궤적.
- `windX.png`: 8프레임, 896×64. 잔선을 줄인 흰색 대각선 검기와 교차 잔상.
- 미리보기 기본 동작은 X자 2연속 베기이며 사격을 포함한 9개 동작/이펙트를 선택할 수 있다.
- 0기준 공격 프레임 2–9에 검기 0–7을 대응한다. 명세는 `manifest.json`의 `combo` 참조.
- 기존 `compat27.png`는 단일 베기 버전을 유지한다. X자 공격은 별도 12프레임 상태 연결이 필요하며, 실제 2회 피해 판정은 구현하지 않았다.
- 재생성 순서: `node docs/art/gunblader-sd/pack.mjs`, `node docs/art/gunblader-sd/pack-x.mjs`.
- 수정본 검증: `verify.mjs`가 총 10개 시트와 X자 두 타격·사격 미리보기를 검사한다. `x-first-preview.png`, `x-second-preview.png` 참고.

| 파일 | 프레임 | PNG 크기 | 권장 재생 |
|---|---:|---|---|
| idle.png | 4 | 448×64 | 5fps 반복 |
| walk.png | 8 | 896×64 | 14fps 반복 |
| run.png | 6 | 672×64 | 16fps 반복 |
| dash.png | 4 | 448×64 | 20fps 단발 |

모든 셀은 **112×64**. ART_GUIDE의 현재 캐릭터 전용 규격을 사용한다.
가로 한 줄, 투명 RGBA, 이진 알파(0/255), 오른쪽 기준, 하단 중앙 피벗.
캐릭터 6개 동작은 공통 96색 팔레트, 검기는 흰색과 옅은 청회색 6색 이하.
원화는 동작별로 동일 배율을 적용하고 좌우 기준점을 조정하여 무기를 자르지 않았다.
검기에는 캐릭터가 포함되지 않는다.

## 사용

`index.html`에서 7개 애니메이션을 동시에 비교하고, 배경 위 동작 선택·일시정지·
한 프레임 이동·좌우 반전·0.25/0.5배속·검기 표시를 확인할 수 있다.

`compat27.png`를 CharacterSprite.SHEET_URL에 지정하면 기존 대기 0–3,
걷기 4–10, 검 11–18, 총 19–26 프레임 배열로 읽을 수 있다.
걷기 원본 8프레임을 호환본에서는 [0,1,2,3,5,6,7]로 재배열한다.
호환본에는 달리기와 대시가 포함되지 않으며, 별도 상태 시트를 읽는 연결이 필요하다.
현재 엔진은 달리기 별도 상태가 없고 대시에 걷기 프레임을 쓰므로, 실제 전환은
별도 구현 작업이다. 이 납품은 게임 사용 가능한 이미지/메타데이터이며 활성 캐릭터 교체가 아니다.

검기는 공격의 0기준 2번 프레임부터 시작한다. 미리보기에서는 캐릭터보다 앞에
겹쳐 표시하며, 게임의 실제 검 이펙트 기준점·재생 타이밍은 적용 시 조정해야 한다.
표시 fps는 아트 미리보기 값이며 공격 쿨다운·피해량·이동속도를 바꾸지 않는다.

## 검증

- `node docs/art/gunblader-sd/pack.mjs`: 원화에서 재현 가능한 PNG 패킹.
- `node docs/art/gunblader-sd/verify.mjs`: 8개 시트의 규격·모든 프레임 내용·중복 여부·
  알파·투명 모서리·발 하단·팔레트 검사 및 브라우저 모션/반전/검기 캡처.
- `verification.json`: 검사 결과. `sheets-contact.png`: 전체 프레임 확대본.
- `attack-preview.png`, `run-preview.png`: 독립 모션 비교 화면 캡처.
- 전체 프로젝트 QC는 기본 캐릭터를 사용하는 기존 게임 회귀 검사이며, 신규 시트는
  위 전용 검증과 프레임 접촉 시트로 별도 확인한다.

최종 결과: 전용 시트/브라우저 검사 통과, 전체 QC 재실행 42/42 통과,
콘솔/네트워크 오류 0건. `qc-out/contact.png`와 신규 시트 접촉 시트·모션 캡처를
육안 확인했고 `git diff --check`도 통과했다. 최초 전체 실행은 기존 trait-slots
피해량 검사 1건(67.5/기대81.0)이 실패했으나 코드 수정 없이 전체 재실행에서 통과했다.

생성 원화의 포즈는 수작업 애니메이터가 그린 연속 원화와 같은 수준의 균일성을
보장하지 않는다. 실제 게임 교체 시 빠른 공격 연결과 코트 움직임을 다시 검수한다.
